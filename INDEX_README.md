# Missing `index.html` / full player

The complete working player is too large to push through the API tools in one go.

**To get a working copy on this repo:**

1. Download the latest zip from the conversation (or the release if you published one)
2. On this repo page click **Add file → Upload files**
3. Upload at least:
   - `index.html`
   - `player.js`
   - the entire `assets/` folder
4. Commit

After that, open `index.html` from the repo (or enable GitHub Pages).

The zip includes:
- Authentic amber + neon cyan movie frames (no fake CSS hue-rotate)
- Amber / Blue theme switch
- CRT scanlines + retro glow
- All 83 original clips
