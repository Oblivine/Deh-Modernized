# X3 Amber Player (Deh-Modernized)

Interactive recreation of the **Eonon X3** head-unit interface.

## One-click preview

After you download and unzip this project, double-click **[PREVIEW.html](PREVIEW.html)**.

That file opens the player in your browser. If the redirect is blocked, it also has a direct link to `index.html`.

> The full player (`index.html`, `player.js`, and `assets/`) has to be in the same folder as `PREVIEW.html`. Those files ship in the project zip. This GitHub tree currently has the launcher and the docs; upload the zip contents here if you want the live files in the repo too.

**Theme**: Settings → Display → Illumination color → Blue (original OEL cyan from the Carozerra `.lkd` files) or Amber.
